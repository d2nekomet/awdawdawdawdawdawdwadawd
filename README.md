# Bot Franchise

Главный бот продаёт доступ, а внутри — 15 готовых инструментов. Каждый инструмент — отдельный
Telegram-бот, которого владелец создаёт в один клик. Оплатил подписку один раз — все боты бесплатны.

## Что внутри

| Инструмент | Что делает |
|---|---|
| 🎬 TikTok загрузчик | Скачивает видео без водяного знака (yt-dlp) |
| ☁️ Drive | Принимает файлы, фото, видео и сохраняет в drive.unlim-projects.lol |
| 📣 Управление каналом | Публикация через подтверждение, закрепление, удаление постов |
| 📈 Аналитика канала | Подписчики, админы, динамика за 7 и 30 дней (снимки каждые 6 ч) |
| 🔎 Метаданные | ID, данные файлов, источник пересланных постов, профиль |
| 🔳 QR-генератор | Текст и ссылки в QR-код |

| ⏰ Напоминания | `/remind 10m текст`, переживают перезапуск |
| 📊 Опросы | `/poll Вопрос | вариант | вариант` |

## Оплата

- **Telegram Stars** (`stars`) — нативный инвойс `XTR`, pre-checkout, возврат через `/refund`.
- **Crypto Bot** (`cryptobot`) — счета Crypto Pay API. Оплата проверяется опросом, поэтому
  вебхук и публичный адрес не нужны: бот работает с ноутбука за NAT.

Включаются в `.env`: `ENABLED_PAYMENTS=stars,cryptobot`.

### Как добавить свой способ оплаты

1. Создайте класс в `franchise/payments/`, унаследовав `PaymentProvider`:
   - `start(bot, user_id, days)` — показать пользователю счёт или ссылку;
   - `poll()` — (если нужен опрос) вернуть список оплаченных счетов как `Settled`.
2. Зарегистрируйте его в `franchise/payments/__init__.py` в `build_providers`.
3. Добавьте название в `ENABLED_PAYMENTS`.

Зачисление идемпотентно: один и тот же `(provider, external_id)` не продлит подписку дважды.

## Архитектура

```
main.py                  точка входа: главный бот + запуск дочерних
franchise/
  config.py              настройки из .env
  db.py                  SQLite: пользователи, подписки, платежи, боты, kv-хранилище плагинов
  billing.py             доступ, зачисление оплат, опрос провайдеров
  payments/              способы оплаты (Stars, Crypto Bot, ...)
  hub.py                 главный бот: меню, каталог, создание ботов, подписка, админка
  runtime.py             запуск каждого дочернего бота в своём Dispatcher со своим токеном
  drive.py               клиент Drive
  ui.py                  единый стиль сообщений и клавиатур
  plugins/               15 инструментов: один файл = один бот, SPEC в конце файла
tests/test_core.py       тесты оплат, провайдеров, плагинов
```

Дочерний бот работает, пока у владельца активна подписка. Пользователи дочернего бота ничего не платят.
Админские инструменты (`owner_only=True`) отвечают только владельцу.

### Что используется из последнего Bot API

- Telegram Stars (`XTR`), `pre_checkout_query`, `refund_star_payment`
- **Managed Bots**: `KeyboardButtonRequestManagedBot` + апдейт `managed_bot` + `getManagedBotToken`.
  Пользователь создаёт бота кнопкой, без копирования токена из BotFather. Ручной ввод токена тоже работает.
- `forward_origin` для метаданных пересланных сообщений
- `copyMessage` для публикации в канал
- Опросы с множественным выбором

Реализация — aiogram 3.31 (Bot API 10.3).

## Запуск на ноутбуке

Нужен Python 3.11+.

```bash
git clone <этот репозиторий> && cd awdawdawdawdawdawdwadawd
python -m venv .venv && source .venv/bin/activate      # Windows: .venv\Scripts\activate
pip install -r requirements.txt
cp .env.example .env                                   # заполните значения
python main.py
```

Подготовка в BotFather:

1. У главного бота включите **Bot Management Mode** (Bot Settings → Bot Management). Без него кнопка
   «Создать бота в Telegram» не появится.
2. Для Crypto Bot создайте приложение в @CryptoBot → Crypto Pay → Create App и вставьте токен в `CRYPTOBOT_TOKEN`.
   Для тестов поставьте `CRYPTOBOT_TESTNET=true`.
3. Stars отдельного токена не требуют.

Бот работает через long polling, открытые порты не нужны.

### Drive

Клиент отправляет файл POST multipart-полем `file` на `DRIVE_UPLOAD_URL` с заголовком
`Authorization: Bearer <DRIVE_API_TOKEN>` и ожидает JSON с полем `url` (или `link`).
Этот контракт я не смог проверить: песочница не имеет доступа к `drive.unlim-projects.lol`.
Если ваш API отличается, поправьте `DriveClient.upload` в `franchise/drive.py`, остальное не меняется.

## Безопасность

- `.env` и `data/` в `.gitignore`. В `data/` лежат токены созданных ботов, храните папку приватно.
- Токен главного бота, который был передан в чате, стоит перевыпустить: `/revoke` в @BotFather, затем обновить `.env`.
- Ссылки проверяются на приватные и внутренние адреса (`links`), загрузки ограничены 20 МБ (лимит Bot API) и 50 МБ (видео).
